## Projetos em destaque

- [**IndieFlow**](https://github.com/Laurima104/IndieFlow) — API REST para organizar projetos de jogos, membros, tarefas e bugs, desenvolvida com Java, Spring Boot, JPA e PostgreSQL.
- [**Aplicativo de Segurança Digital**](https://github.com/Laurima104/App-de-Seguranca-Digital) — projeto educacional para ensinar boas práticas de segurança e privacidade digital. A proposta inclui módulos de aprendizagem, quizzes e acompanhamento de progresso.

- [**Sistema de Ordem de Serviço**](https://github.com/Laurima104/sistema.ordem.servico) — projeto em Java voltado à gestão de ordens de serviço.
